# SumStories
Repository for a Capstone project in the RIT Software Engineering MS program.

# Running the Demo
To run this application, you will need to have PostgreSQL and the .NET runtime installed.

1. Clone the repository
2. From the main repository folder, open a bash window and execute the following command:

```
bash demo/demo_setup.sh
```

3. Open the solution using Visual Studio or Visual Studio Code and run Program.cs
